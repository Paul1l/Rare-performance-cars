# Apex Select

Premium landing page for rare enhanced performance car sourcing across Europe.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Responsive premium landing page
- Curated inventory section
- Interactive category filters
- Scroll reveal animations
- Mobile navigation
- Contact form validation
- GitHub Pages ready

## Project structure

```text
Rare-performance-cars/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── .gitignore
└── README.md
```

## GitHub Pages

After pushing the project to GitHub:

1. Open the repository settings.
2. Go to **Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/root`.
5. Save the settings.

The site will be available at:

```text
https://paul1l.github.io/Rare-performance-cars/
```
